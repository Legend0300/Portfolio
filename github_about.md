- **AKS platform** (Azure): Terraform to AKS, a Go auth API and WebSocket chat service, ingress-nginx, Kustomize, and cost levers written down. [Repository](https://github.com/Ahmed-Mansur/Go-Microservice-Pipeline)
- **DevOps Buddy** (Cloudflare): an AI-native, read-only-by-default DevOps platform on Workers and D1, with an approval-gated write path and a data-driven catalog of 54 Cloudflare products. [Live demo](https://devops-buddy.ahmed-mansur-bhatti.workers.dev/demo)
